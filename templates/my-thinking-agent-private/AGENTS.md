# my-thinking-agent-private

This private repository stores the durable information used by
`my-thinking-agent` across devices.

- Verify private visibility, repository access, and the destination device before adding data.
- Never store passwords, API keys, OAuth tokens, private keys, raw conversations, or directly identifying information.
- Keep learning records concise, anonymized, and classified as `public`, `internal`, or `confidential`.
- The normal MCP configuration exposes no more than `internal` records. A `confidential` record requires a separately configured local session.
- Synchronize through a JJ bookmark and Pull Request; do not push directly to `main`.
- A destructive operation, external send, publication, credential change, or irreversible action always waits for an explicit user instruction.
